# 绿色瓶子抓取投放任务

> 本页记录最初三轮结果；后续相机、观测、动作排查与复测见 [OBSERVATION_ACTION_AUDIT.md](OBSERVATION_ACTION_AUDIT.md)。

已加入平台、自由瓶子、开口垃圾桶和实际夹爪物理反馈，并测试完整任务。
**官方 VLA 的三次 90 秒尝试均未进入抓取阶段；完整任务成功 0/3。**
独立脚本夹爪物理对照完成了抓取、抬升和松手落桶；它不是 VLA 或 G1 任务成功。

## 场景与机器人接入

- 平台顶面高 0.74m；绿色瓶子约 0.12kg、直径 6cm、高 24.8cm，具有自由关节和真实碰撞。
- 垃圾桶内部开口为 30×30cm，底面高 0.04m、桶沿高 0.62m，使用底板和四面独立桶壁，顶部没有盖。
- 为匹配策略的单标量开合接口，加入双指平行夹爪近似模型，最大开口约 96mm。
- 保留原 G1/SDK 的关节和电机映射。工具刚性安装在腕部；瓶子没有焊接、附着或运动学跟随约束。
- 原始 `pose` 消息中的 `action_hand_left/right` 通过独立仿真桥驱动夹爪，反馈来自实际滑动关节开度。
- 三路相机返回真实渲染图像；头部视角拓宽以覆盖平台与桶，腕部相机使用近似挂载。

模型仍为官方 `12tasks_12full-teleop`。VLA 只接收图像、机器人状态和文字指令，
没有接收瓶子坐标或可达性求解结果。原始 SONIC/TensorRT 全身控制链保持不变。

## 成功判据

1. 抓取：同一夹爪两指均与瓶子接触，法向力各超过 0.2N，闭合命令有效，并持续至少 0.15 秒。
2. 抬升：抓取成立后，瓶子底部离平台超过 6cm，保持双指接触至少 0.25 秒。
3. 投放：曾完成抬升；夹爪已实际张开，所有夹爪表面与瓶子不再有显著接触；
   瓶子整个包围盒在桶内，速度低于 0.15m/s、角速度低于 1rad/s，连续稳定至少 0.8 秒。

时间阈值使用物理仿真时间。桶壁接触允许 3mm 求解器穿透容差，不要求瓶子离桶壁悬空。
瓶子预先在桶内、单指碰触、搭在桶沿、仍在运动或仍由夹爪支撑，都不能直接算成功。

三次评估记录中的手指—瓶子接触力最大值均为 0；夹爪命令始终接近全开。
例如右夹爪命令最小值约为 0.988–0.990，1 表示全开。
瓶子未被抬离平台，不能把机器人走近平台或保持站立算作完成任务。

这是本次近似仿真场景的小样本结果，不能当作论文基准成功率。
失败的直接观测是没有接近并闭合夹爪完成抓取；其唯一根因尚未确定。
真实相机、夹爪模型和场景外观仍未与训练分布严格对齐。

## 物理正向对照与可达性

独立对照使用程序控制的夹爪载台，没有 VLA、SONIC 或 G1 身体动力学。
瓶子是自由刚体，靠接触摩擦夹持，没有物体焊接约束或瞬移。
对照约在 3.31 秒确认抓取、5.05 秒确认抬升，瓶底最高离平台约 19.2cm，
约在 11.94 秒确认松手后稳定落桶。录像已直接标注 `SCRIPTED ... NOT VLA / G1`。
此对照验证夹爪接触、容器碰撞与评分链路，不证明 G1 动力学下任务成功。

额外使用 G1 模型和关节限位检查了几何可达性：预抓取点、抓取点、抬升点及桶口内的
一个投放点均存在位置误差小于 15mm 的右臂 IK 解。固定站姿下桶口中心的求解误差约 19mm；
投放任务不要求落在正中心。该检查不验证避碰轨迹或动态控制可行性。
